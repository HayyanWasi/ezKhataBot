# EzKhata website (Vercel)

Signup page for shopkeepers and the super admin dashboard. The backend APIs run on Render (`app/api/`).

- `/signup` — a shopkeeper asks for the bot (the admin approves it)
- `/login` → `/admin` — overview, signup requests, shops, employees, chats, problems

Env: `NEXT_PUBLIC_API_URL=https://ezkhata-bot.onrender.com`

    npm install
    npm run dev      # http://localhost:3000
